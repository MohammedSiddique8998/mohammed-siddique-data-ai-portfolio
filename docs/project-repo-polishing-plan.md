# Portfolio Project Roadmap

This roadmap keeps public GitHub repositories focused on professional portfolio value. Each project should read like an independent product-style or research-style implementation with clear business context, reproducible code, realistic limitations and safe public data.

## Public Repo Safety Rules

- Do not upload private briefs, answer sheets, rubrics, grading material, restricted datasets, zipped submissions or raw draft files.
- Use public data, synthetic demo data or clear instructions for adding permitted local data.
- Rewrite problem statements in original language and frame each repository as independent learning, implementation and experimentation.
- Keep reproducible code, concise documentation, selected plots, requirements and clear run instructions.

## Published Repositories

### 1. Intelligent Visual Classification Pipeline

Repository: `intelligent-visual-classification-pipeline`

Public focus:
- Computer vision workflow for three-class image classification.
- Reproducible training and evaluation scripts.
- Responsible non-clinical framing and model-card documentation.
- Metrics and plots must be produced from the current pipeline and permitted local data.

### 2. Adaptive Decision Optimization Engine

Repository: `adaptive-decision-optimization-engine`

Public focus:
- Sequential decision simulation for exploration versus exploitation.
- Random, greedy, epsilon-greedy and UCB policies.
- Average reward and optimal-action-rate plots.
- Clear limitations around simulated stationary environments.

### 3. Customer Feedback Theme Discovery

Repository: `customer-feedback-theme-discovery`

Public focus:
- Text preprocessing, TF-IDF vectorisation and K-Means clustering.
- Silhouette-based cluster-count selection.
- PCA visualisation and top-term interpretation.
- Safe synthetic demo corpus with instructions for adding permitted local data.

### 4. Real-Time Customer Insight and Churn Intelligence Platform

Repository: `real-time-customer-insight-churn-platform`

Public focus:
- Customer risk scoring and segmentation.
- Retention recommendation logic.
- Interactive Streamlit dashboard.
- Synthetic customer-interaction dataset.
- Recruiter-friendly architecture and business impact explanation.
